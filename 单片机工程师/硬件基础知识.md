# 电阻篇:阻值识别、分压与限流
阻值越大电压越大
## 欧姆定律
$$I=\frac{U}{R},  R=\frac{U}{I},   U=I*R$$
$$I是电流,R是电阻,U是电压$$

## 电阻的阻值识别
![[msedge_UsAAxX0zgs.png|500]]
![[msedge_YUAG8IZFkp.png|500]]![[msedge_Z8Khchi90f.png|500]]

## 电阻的功率
$$P=I*U,P=I^2*R,P=\frac{U^2}{R}$$
$$P是功率,I是电流,R是阻值,U是电压$$
## 电阻的限流作用
当供电电压大于负载的工作电压时,可以利用电阻限流
电路中不能超过电阻的功率,同时尽可能置工作在供电电压与负载工作电压相差不大或者工作电流很小的场景
## 电阻的分流功能
并联电阻是分流
$$电阻分流公式:I_总=I_1+I_2+I_3......$$
## 电阻的分压功能
串联电阻是分压
$$电阻分压公式:V_R=\frac{(V_1-V2)*R_2}{R_1+R_2}+V_2$$
$$V_2大部分是GND(0V)$$

# 电容篇:储能、延时与滤波
## 电容是什么
两块不相连通的导体加上中间的绝缘材料.
电解电容分方向,分正极负极,接反 和 电压超过额定电压 会爆炸
## 常见电容特性
![[msedge_AgSf7WQmDg.png|500]]

| 类型         | 容量范围           | 特点                                         | 嵌入式典型用途             |
| ---------- | -------------- | ------------------------------------------ | ------------------- |
| 陶瓷电容（MLCC） | pF ~ 100µF     | 无极性、便宜、高频特性好、ESR 低；大容量时容量随电压下降（DC bias 效应） | 去耦（0.1µF 标配）、滤波、振荡器 |
| 电解电容（铝电解）  | 0.47µF ~ 上万µF  | 有极性（接反会爆）、容量大、ESR 偏高、低温容量下降                | 电源滤波、储能、大容量旁路       |
| 钽电容        | 0.1µF ~ 1000µF | 有极性、容量密度大、ESR 低、耐压余量不足会着火                  | 高可靠电源滤波（慎用，浪涌易烧）    |
| 薄膜电容       | nF ~ µF        | 无极性、精度高、损耗小、稳定                             | 精密电路、音频、电机吸收尖峰      |

## 课程答疑_电容两端电压不能突变
真正不能突变的是电容两端压差 Vc = VA − VB
![[msedge_nfvBiZ2YzN.png|350]]
比如说S2闭合,此时A点电压从0V->5V,因为电容两端电压不能突变,所以B点电压也从0V->5V,经过一段时间B点从5V->0V,这时候打开S2,闭合S3,B点从0V->5V,因为电容两端电压不能突变,所以A从5V->10V

| 阶段            | 状态          | A 点       | B 点             | Vc = VA−VB |
| ------------- | ----------- | --------- | --------------- | ---------- |
| ① 闭合 S1       | S1 通、S2 断   | 0→5V（接电源） | 悬空，经电容耦合被拉到 ~5V | ≈0V        |
| ② 保持 S1       | 充电稳态        | 5V        | 经泄漏路径回落到 0V     | 5V（充满）     |
| ③ 断开 S1、闭合 S2 | S2 把 B 接 5V | 5V→10V    | 0V→5V（跳变）       | 5V（不变）     |
把电容想成一根橡皮筋（可变形导线）：上电瞬间它真的像导线，把 A、B 两个极板"绑"成同一个电位——所以 B 瞬间被拉到 5V。但橡皮筋会越拉越紧（充电），渐渐失去"导线"作用，最后变成绝缘体（开路）。于是 B 就失去了支撑，被 GND 慢慢"拽"回 0V。整个过程里，A 始终被电源死死摁在 5V，真正在变的是 B：5V → 0V。
## 利用电容的储能特性实现上电延时
电容可以简单理解成一个小电池,充电速度和电容的大小以及充电电流有关
$$电容充电时间常数:τ = R*C,R是电阻,C是电容$$
$$
电容充电时间:V_C(t) = V_{CC}\left(1 - e^{-\frac{t}{RC}}\right)
$$
电容的端电压达到最大值的0.63倍时所需要的时间
![[msedge_0X4RBiFBMU.png|500]]
## 电容的储能特性实现断电延时
$$电容放电公式:V(t) = V_0 \times e^{-\frac{t}{RC}}$$
$V_0$：断电起始电压（通常是 $V_{CC}$，如 3.3V）
$R$：放电回路等效负载电阻
$C$：电容值
$t$：断电后经过的时间
$$最低工作电压 $V_{min}$，可维持的时间：t_{hold} = -RC \times \ln\left(\frac{V_{min}}{V_0}\right)$$

## 电容的稳压功能和滤波功能
假设电路中有两个用电电流不同的电器,A电器工作电流是10mA,B电器工作电流是1A,当B电器突然接入电路中,电流会从10mA上升到1A,会导致电压突然降低,再恢复到电源电压,电容不能完全防止电压下降，它只能减缓下降的深度和速度，为电源调整赢得时间。
## 容抗的计算公式
容抗（Capacitive Reactance） 表示电容对交流电的阻碍作用
$$
X_C = \frac{1}{2\pi f C}
$$

| 符号     | 含义                                     | 单位     |
| ------ | -------------------------------------- | ------ |
| $X_C$  | 容抗（capacitive reactance）——电容对交流电流的阻碍大小 | 欧姆（Ω）  |
| $f$    | 交流信号的频率                                | 赫兹（Hz） |
| $C$    | 电容的电容量                                 | 法拉（F）  |
| $2\pi$ | 圆周率常数，来自角频率 $\omega = 2\pi f$          | 无量纲    |

频率越高，容抗越小——电容对高频信号阻碍小，容易通过。
频率越低，容抗越大——对直流（$f = 0$），容抗无穷大，电容相当于断路。
这就是电容的"隔直通交"特性。
## 低通滤波电路的本质原理
（a）频域视角（容抗分压）：R 和 C 构成分压器，C 的容抗 $X_C = \dfrac{1}{2\pi f C}$。频率越高 $X_C$ 越小，电容支路阻抗越小 → 高频分量被分压到几乎为零 → Vout 上只剩低频。
$$
V_{out} = V_{in} \times \frac{X_C}{\sqrt{R^2 + X_C^2}}
$$
（b）时域视角（充电/放电）：输入突然变化时，电容电压不能突变，只能以 $\tau = RC$ 的时间常数缓慢跟随 → 快速抖动被"抹平"，输出是平滑的缓变信号。
简单来说就是电流的速度太快,电容跟不上
![[msedge_895y7i126L.png|375]]
定义：输出衰减到输入的 70.7%（-3dB，功率减半）时的频率：
$$
截止频率:f_c = \frac{1}{2\pi RC}
$$
实例：$R = 10\text{k}\Omega$、$C = 10\text{nF}$
$$
f_c = \frac{1}{2\pi \times 10^4 \times 10^{-8}} \approx 1.6\text{kHz}
$$
即：1.6kHz 以下的信号基本无损通过，以上开始衰减。

| 频率 vs $f_c$ | 衰减程度 |
| --- | --- |
| $f \ll f_c$（如 $0.1f_c$） | 几乎无衰减（$-0.04\text{dB}$） |
| $f = f_c$ | $-3\text{dB}$（$70.7\%$） |
| $f = 10f_c$ | $-20\text{dB}$（衰减 10 倍） |
| $f = 100f_c$ | $-40\text{dB}$（衰减 100 倍） |

## 低通滤波电路的基本作用

| 场景         | 低通滤波干什么                          |
| ---------- | -------------------------------- |
| 传感器信号调理    | 滤掉工频干扰、高频噪声，让 ADC 采到干净的直流/缓变信号   |
| PWM → 模拟电压 | PWM 是高频方波，低通后变成平滑的直流电压（DAC 替代方案） |
| ADC 抗混叠    | ADC 采样前滤掉超过 ½ 采样率的频率，防止混叠失真      |
| 电源去噪       | 电源线上纹波、毛刺被滤掉，给芯片干净供电             |
| 音频低通       | 滤掉高频嘶声，只留低频（如低音炮分频）              |
只能工作在一些工作电流比较小的电路中/信号传输的电路
RC 适合"小电流、信号级"（省成本、无干扰）
## 高通滤波电路工作原理
（a）频域视角（容抗分压）：R 和 C 构成分压器，C 的容抗 $X_C = \dfrac{1}{2\pi f C}$。频率越低 $X_C$ 越大 → 电容上分压越大 → Vout 上低频被压掉；频率越高 $X_C$ 越小 → 高频几乎无衰减通过。
$$
V_{out} = V_{in} \times \frac{R}{\sqrt{R^2 + X_C^2}}
$$
（b）时域视角（微分器）：电容电压不能突变，输入跳变时输出先猛跳一下再按 $\tau = RC$ 衰减回零——这正是"提取变化量、丢弃直流"的体现。
## 高通滤波电路常见应用场景

| 场景        | 要挡掉什么       | 要留下什么           | $f_c$ 取多低 | 电容数量级            |
| --------- | ----------- | --------------- | --------- | ---------------- |
| 音频级间耦合    | 直流偏置        | 20Hz~20kHz 音频   | ~2Hz      | 1~10μF           |
| 心电前端      | 电极极化直流、基线漂移 | 0.05Hz~150Hz 心电 | ~0.05Hz   | 0.1~1μF（配 MΩ 电阻） |
| 高音分频      | 中低频大功率      | 4kHz 以上         | ~4kHz     | 2~10μF           |
| 示波器 AC 耦合 | 直流          | 全部交流            | ~1Hz      | 内部已配好            |
| 射频隔直      | 直流偏置        | RF 信号           | 远低于工作频    | 10~100pF         |

# 电感篇:感抗与滤波原理
## 电感是什么
电感就是一根导线加一个磁性材料,生活中所有由线圈组成的器件都是电感
## 电感的基本特性
流过电感的电流不能突变
当电路中没有电感时,电流会跳变,加上电感后,相较于未加电感的电路电流会慢慢上升,因为电流慢慢上升所以电压也是慢慢上升的
![[multisim_FfH5gPDzmw.png]]
![[multisim_z8OyO9kGfd.png]]
 **电感只限制电流的变化速度但不改变电流最大值**

## 电感回路的电阻突然变很大会怎样
![[multisim_sIQ7cfbRdA.png]]
电感回路的电阻突变,变得很大,电感会感生出一个很高的电压,容易击穿元器件,应用电感时要考虑电感的持续回流
电感为了保证自身的电流不突变,会产生一个特别大的电压
## 电感的感抗计算公式
$$R_l=2πfL,其中f是频率.L是电感值R_l感抗$$
关键特性
- 与频率成正比：频率越高，感抗越大（$X_L \propto f$）
- 与电感量成正比：电感越大，感抗越大（$X_L \propto L$）
- 直流时：$f = 0$，感抗为 0，电感对直流相当于短路
- 高频时：感抗很大，电感相当于开路，可用作扼流/滤波
## 电感的低通滤波原理以及适用场景
$$截止频率:f_c = \frac{R}{2\pi L},f_c是截止频率,R是电阻,L是电感$$
电感对交流电呈现感抗 $X_L = 2\pi fL$，频率越高，感抗越大。利用这一特性，将电感与负载串联，就构成了最基本的 RL 低通滤波器

LR 适合"大电流、功率级"
## 电感的高通滤波原理
工作原理：利用电感感抗随频率升高而增大的特性（$X_L = 2\pi fL$），与电阻构成分压
截止频率：$f_c = \dfrac{R}{2\pi L}$，高于 $f_c$ 的信号通过，低于 $f_c$ 的被衰减
高通滤波会把直流电压偏置滤掉
## LC低通滤波原理
$$截止频率:f_c = \frac{1}{2\pi\sqrt{LC}},L电感,C电容$$
双重衰减：高频信号既"过不了电感"（串联阻碍），又被"电容短路掉"（并联旁路），所以 LC 滤波效果远好于单用 L 或单用 C。
每倍频程 $-12\,\text{dB}$

LC 独有的问题：谐振
LC 组合在 $f_c$ 附近会形成串联谐振/并联谐振，带来两个特殊现象：
1.  截止频率处的尖峰（过冲）
- 理想无损耗 LC 在 $f_c$ 处增益可达无穷大（谐振）
- 实际中靠电感的直流电阻、电容 ESR、负载电阻提供阻尼
- 阻尼不足时，截止频率附近会出现增益尖峰，信号被"过冲"放大
2. 振铃（ringing）
- 输入阶跃信号时，LC 会振荡，输出出现衰减振荡波形
- 阻尼越小，振铃越明显、持续时间越长
因此**实际 LC 滤波器常并/串联阻尼电阻（变成 LCR 滤波）** 或用合适的负载阻抗来抑制谐振，避免尖峰和振铃。

## 全波整流电路工作原理
全波整流让交流电的正、负两个半周期都被利用，输出波形始终为单一方向——相比半波整流（浪费一半周期），效率更高、纹波更小。

全波整流有两种实现方式：双二极管（中心抽头变压器）式和桥式。
![[msedge_vNAEjlAQqe.png]]
## 二极管的钳位功能
![[multisim_3BQgJ91hjQ.png]]
利用二极管的导通电压特性,实现对信号线进行钳位
二极管把节点电压限制在某个阈值内——这里是它的正向导通压降 0.7V。
电路只能钳到 0.7V 附近。如果想把节点钳在 2.5V 或 5V，就得换稳压二极管
## 二极管控制电路的电流方向
二极管就是电流方向的单向阀门：电流只能从阳极（A）流向阴极（K），反向则截止。利用这一点，可以在电路中"规定"电流的走向，衍生出整流、续流、防反接、防倒灌等典型应用。

| 应用     | 二极管接法    | 控制方向的作用     | 保护对象    |
| ------ | -------- | ----------- | ------- |
| 整流     | 串联       | 只放行正向电流     | —（功能转换） |
| 续流     | 反并联在电感两端 | 给反向感应电流提供通路 | 开关管     |
| 防反接    | 串联在电源回路  | 阻止反向电流      | 后级电路    |
| OR-ing | 每路各串一个   | 阻止电源间倒灌     | 电源本身    |
| 电荷泵    | 组合网络     | 引导电荷流向      | —（功能转换） |
## 二极管的最大反向耐压
最大反向耐压指二极管反向偏置时能安全承受的最高电压，超过该值二极管进入反向击穿。数据手册中对应参数为 $V_{RRM}$（最大重复反向峰值电压）。

| 对比项   | 齐纳击穿            | 雪崩击穿        |
| ----- | --------------- | ----------- |
| 物理机制  | 强电场直接拉出电子（场致电离） | 载流子碰撞电离链式倍增 |
| 掺杂浓度  | 高（高掺杂）          | 低（轻掺杂）      |
| 耗尽区宽度 | 极薄              | 较宽          |
| 反向电压  | 低（通常 < 5~6V）    | 高（通常 > 6V）  |
| 温度系数  | 负（电压随温度略降）      | 正（电压随温度略升）  |
| 击穿特性  | 陡峭、硬            | 稍平缓         |
| 噪声    | 较大              | 较小          |
约 5~6V。低于 6V 以齐纳击穿为主，高于 6V 以雪崩击穿为主；6V 附近两种机制并存，此时温度系数接近零——这正是 6V 左右稳压管温漂最小的原因。
## 稳压二极管的基本功能
稳压二极管（Zener Diode） 工作在反向击穿区，利用击穿区"电流大幅变化、电压几乎不变"的特性，把输出端电压稳定在固定值 $V_Z$。

| 功能                  | 应用说明                                                                                |
| ------------------- | ----------------------------------------------------------------------------------- |
| 提供稳定电压（稳压电源 / 电压基准） | 小电流稳压电源为电路提供稳定的 3.3V / 5V / 12V；基准电压源给 ADC、比较器、运放提供精确参考电平；电平转换钳制在固定电位，供后级使用         |
| 电压保护 / 钳位（过压时"泄放"）  | 过压保护：电压超过 $V_Z$ 时导通泄放，保护后级；ESD / 浪涌钳位：把瞬态高压钳在 $V_Z$ 以内（类似 TVS）；钳位电路：限制信号幅度不超过 $V_Z$ |

# 三极管篇:开关电路与设计计算
## 三极管的基本结构
![[msedge_ISAQ09FEYR.png]]
![[msedge_wzMnZExgj2.png]]
### 双极晶体的结构和符号
三个区:
- 发射区载流子多,参杂浓度高
- 集电区载流子少,参杂浓度低,面积大
- 基区很薄
三个极:   发射级   基极   集电级
两个结:  发射结  集电结
箭头方向 = 电流方向 = 发射结正偏方向
NPN：发射极箭头向外
PNP：发射极箭头向内
## 三极管的开关功能
C(发射极)和E(集电极)不导通,如果给B(基极)极添加一个电流$I_B$会让C和E之间导通,这时在C上串联一个元器件就会导通
![[multisim_HC7OEUXXXn.png]]
## 三极管开关电路设计注意事项及计算方法
当流经I_C的电流小于100mA时,流经I_B的电路上添加的电阻值取1K~10K都可以
当大于100mA时,不合适的R_B会导致电流不够驱动元器件以及三极管会发烫严重
### 判断三极管是否工作在饱和导通的条件
| 角度   | 条件                                                             | 工作状态   |
| ---- | -------------------------------------------------------------- | ------ |
| 电压角度 | $V_ce = V_cc$（流经发射极C的电压等于电源电压）                                 | 断开（截止） |
| 电压角度 | $V_ce <= 0.3V$（流经发射极C的电压小于或等于0.3V）                             | 饱和（导通） |
| 电压角度 | $0.3V <= V_ce <= V_cc$                                         | 放大     |
| 电流角度 | $I_B < \dfrac{I_C}{\beta}$（流经基极的电流小于流经发射极/电流放大倍数）              | 放大     |
| 电流角度 | $I_B = 0$（流经基极的电流等于0）                                          | 截止（断开） |
| 电流角度 | $I_B \gg \dfrac{I_C}{\beta}$（2~5 倍以上）（流经发射极C的电流大于流经发射极/电流放大倍数） | 饱和（导通） |
计算电阻步骤
1. 找出$I_C$ 的最大值
2. $I_B > (2~5)*\dfrac{I_C}{\beta}$ 其中$\beta$ 默认为100,要留出2~5倍的余量
3. $I_B = \frac{V_cc-V_be}{R}$  其中$V_cc$ 是电压$,V_be$ 是三极管的导通电压(0.7V) 
4. $R < \frac{V_cc-V_be}{I_B}$  
## 电子开关什么时候用P管？什么时候用N管？
![[msedge_novhVglACf.png|500]]
因为三极管导通有一个0.7V的压降,5V会被减到4.3V(最大),$V_cb$电压大于$V_be$,会导致三极管发热严重,这是因为使用了NPN型,这时使用PNP型就可以解决
## P型三极管开关电路计算方法
1. 找出$I_C$ 的最大值
2. $I_B > (2~5)*\dfrac{I_C}{\beta}$ 其中$\beta$ 默认为100,要留出2~5倍的余量
3. $I_B = \frac{V_cc-V_eb-V_l}{R}$  其中$V_cc$ 是电压$,V_be$ 是三极管的导通电压(0.7V) $V_l$ 接地取0V,MCU控制低电平取0.1~0.4V
4. $R < \frac{V_cc-V_be-V_l}{I_B}$  
## N型三极管和P型三极管的特性对比

| 特性     | NPN                            | PNP                                  |
| ------ | ------------------------------ | ------------------------------------ |

| 箭头     | 向外                             | 向内                                   |
| 基极电阻公式 | $\dfrac{V_{in} - V_{BE}}{I_B}$ | $\dfrac{V_{CC} - V_{EB} - V_L}{I_B}$ |

| 常用场景   | 低端开关、放大                        | 高端开关、推挽、电源管理                         |
| 性价比    | 高 ⭐                            | 略低                                   |

## 三极管的最大耐压
三极管耐压有多个参数：$V_{CEO}$（C-E 间，最常用）、$V_{CBO}$（C-B 间，最高）、$V_{EBO}$（E-B 间，最小，易忽略）
关系：$V_{CBO} > V_{CES} > V_{CEO}$，基极回路阻抗越低耐压越高
开关电路看 $V_{CEO}$，选型降额 ≥ 2 倍电源电压
最大威胁是感性负载关断尖峰——加续流二极管 + 选高耐压管双管齐下
别忘了同时核对 $I_C$、$P_D$，耐压不是唯一安全参数

## MOS的导通条件
Nmos:$V_g-V_s>V_th$ 当Nmos的g极电压比s极电压大于导通电压(V_th)时,DS之间闭合

## MOS开关电路的设计方法
设计方式和三极管类似,但是g(栅极)可以不用像三极管一样添加限流电阻,因为Mos管是根据电压工作的
## MOS的寄生电容问题
因为g和s之间形成了一个寄生电容, 当导通的时候,V_gs之间的电压就等于电源电压-元器件压降 ,当开关断开,因为寄生电容还是等于高电压,所以元器件不是直接停止工作,而是缓慢的停止,要解决这种问题,需要在g和s之间添加一个电阻,为了释放寄生电容的能力,电阻需要非常大100K
