## 五、两个最重要的公式速记

| 公式 | 含义 |
|---|---|
| I = I_S(e^(U/nU_T) − 1) | PN 结电流方程 |
| I_C = β·I_B，I_E = I_C + I_B | 三极管电流关系 |

**规律性提示：**
- **I** = 电流，**U** = 电压，**P** = 功率
- 大写下标字母指位置：B=基极、C=集电极、E=发射极、S=饱和/反向、M=最大(max)、Z=稳压(齐纳)
- β 是管子固有参数；A_u 是电路参数；r 都是"动态/交流电阻"

1. 本征激发越多,导电能力越好
![[msedge_Es9XcT6Sem.png|375]]
2. 自由电子待负电荷可以开始导电

4. 复合运动:自由运动电子撞上了空穴,一对电子-空穴形成了共价键的价电子

处于热平衡状态的半导体,在一定温度下 ，载流子浓度是一定的。这种处于热平衡状态下的载流子浓度称为平衡载流子浓度。
温度越高本征激发越快,载流子越来越多,复合变得越来越快,最后趋于平衡
### 杂质半导体
#### 一,概念
参入少量的杂志元素
#### 二.N型半导体(negative)
1. 掺入磷(P),磷是+5价,容易形成4价共价键,电子逃脱变得容易
![[msedge_ORmHNfGyli.png|375]]

#### P型半导体
1. 掺入硼(B)，硼是+3价，容易形成3个共价键，产生一个空位（空穴）

	硼原子从邻近硅原子获得一个电子形成4个共价键，使硼原子带上负电被固定在晶体结构中，称之为受主原子（acceptor）
1. 空穴是多数载流子——多子——对温度不敏感
2. 自由电子是少数载流子——少子——对温度非常敏感
3. 因为大量载流子是空穴，空穴带正电（Positive），所以叫 P 型半导体
## PN结
### PN结的形成
![[msedge_NNNNqiUu2M.png|400]]
带正负荷的原子不会动,动的是空穴和自由电子
1. 扩散运动:粒子从浓度高的地方向浓度低的地方运动
2. N区的自由电子向P区运动,P区的空穴向N区运动
3. 载流子在相互扩散中抵消形成了空间电荷区(耗尽层/阻挡层/PN结)
4. 漂移运动:电场力驱动，载流子作定向运动
5. 多子的扩散运动和少子的漂移运动会达到动态平衡
6. 对称结:
	- P 区与 N 区掺杂浓度相等 ：N_A = N_D
	- 耗尽层在两侧对称扩展，两侧宽度相等：x_p = x_n
7. 不对称结
	- 两侧掺杂浓度不等：N_A ≠ N_D
	- 耗尽层主要向轻掺杂一侧扩展（重掺杂侧很窄）
## PN与二极管的特性
### PN结的单项导电性

**PN 结单向导电性**（正偏导通、反偏截止）的本质，是**扩散运动与漂移运动的平衡被外加电压打破**：
**1. 平衡态（无外加电压）**
- 多子扩散形成**内建电场**（方向：N→P，即阻止多子继续扩散）
- 扩散电流 = 漂移电流（少子被内建电场拉回），动态平衡 → 总电流为 0
**2. 正向偏置（P 接正，N 接负）**
- 外加电场方向与内建电场**相反**，削弱内建电场 → 耗尽层变窄
- 多子扩散的阻力减小，**扩散电流大增**（多子浓度高，扩散能力强）
- 外电源不断补充多子 → 形成较大的正向电流（毫安级）
- 当外电压超过**死区电压**（硅约 0.5V，锗约 0.1V）后，电流急剧上升
 ![[msedge_ln173oSLmk.png|450]]
**3. 反向偏置（P 接负，N 接正）**
- 外加电场方向与内建电场**相同**，增强内建电场 → 耗尽层变宽
- 多子扩散被彻底抑制，**扩散电流 ≈ 0**
- 只剩少子的漂移运动 → 反向饱和电流 `I_S`（微安/纳安级，极小）
- 且 `I_S` 几乎不随反压增大（少子数量有限，都被拉过去了），只随温度急剧增大
![[msedge_CWe9QeIvzg.png|475]]!
单向导电性 = 正偏时多子扩散占主导 → 大电流；反偏时多子扩散被抑制、只剩少量少子漂移 → 电流几乎为零。
### PN 结电流方程（肖克利方程 / 理想二极管方程)
$$
I = I_S\left(e^{\frac{U}{U_T}} - 1\right)
$$
- I_S —— 反向饱和电流，由少子浓度决定（少子对温度敏感 → I_S 对温度极敏感）
- U_T —— 温度电压当量，U_T = kT/q（k 玻尔兹曼常数，T 绝对温度，q 电子电荷）
- U —— 外加电压（正偏取正，反偏取负）

### PN结的伏安特性
![[msedge_LX5qvfWyIc.png|475]]
三个区域逐一解读
1. 正向特性（U > 0）
- 电压小于死区电压时（硅 0.5V / 锗 0.1V）：电流极小，几乎不导通
- 超过死区电压后：电流按 I ≈ I_S·e^(U/U_T) 指数急剧上升
- 导通后压降基本恒定：硅管 ≈ 0.7V，锗管 ≈ 0.3V（工程上常说"二极管导通压降 0.7V"）

2. 反向特性（U < 0）
- 反向电压增大，电流基本不增大，恒为 I ≈ -I_S（微安级）——这就是"反向饱和"的含义
- 只要 |U| < 击穿电压，反向都不导通

1. 反向击穿区（U ≤ U(BR)）稳定电压的作用
- 反向电压超过击穿电压 U(BR) 后，电流骤增（雪崩击穿或齐纳击穿）
- 雪崩击穿(高反压、轻掺杂):
	- 反向电压高，电场强，少子被加速到很高速度
	-  高速载流子撞击共价键，撞出新的电子-空穴对，新载流子再撞击……连锁反应，电流骤增
    - 温度升高 → 晶格振动加剧 → 载流子碰撞前路程变短 → <font color="#ff0000">击穿电压随温度升高而增大</font>（正温度系数）
- 齐纳击穿(低反压、重掺杂，<6V):
	- 掺杂浓度高，耗尽层极薄，即使电压不高电场也极强
	- 强电场直接把共价键中的电子拉出来（场致电离），产生大量载流子
	- 温度升高 → 键更容易被拉断 → <font color="#ff0000">击穿电压随温度升高而减小</font>（负温度系数）
- 注意：击穿不一定是损坏——只要限制电流（加限流电阻），稳压二极管就工作在击穿区
- 反向击穿会导致PN结温度提高,会损毁,称为二次击穿

伏安特性 = 正偏指数上升（过了死区就导通）+ 反偏水平截止（≈ -I_S）+ 超过击穿电压电流骤增。三个拐点记三个数：0.5V（死区）、0.7V（导通压降）、U(BR)（击穿）。
### PN结的电容效应
**PN 结电容效应**：结电容由两部分组成——**势垒电容** + **扩散电容**。

**1. 势垒电容 C_B（耗尽层电容）**
- 结构：耗尽层两侧是 P 区、N 区，中间不导电，相当于**平行板电容器**
- `C_B ∝ ε/d`（d = 耗尽层宽度）
- 反偏时主导：**反压越大 → 耗尽层越宽 → C_B 越小**
- 与电压关系：`C_B = C_B0 / (1 + U/U_D)^n`（突变结 n=1/2，缓变结 n=1/3）
![[msedge_DtWgTU90rY.png]]
**2. 扩散电容 C_D（存储电荷电容）**
- 来源：正偏时少子注入对侧，形成**非平衡载流子存储**，其电荷量随电压变化
- 正偏时主导：**正向电流越大 → 存储电荷越多 → C_D 越大**（C_D ∝ 正向电流）
 ![[msedge_pz5Plx53lX.png|350]]
**应用：**
- **变容二极管**：利用反偏 C_B 随电压可调，做调谐/压控振荡器
- **开关二极管的反向恢复时间**：正偏时存储了大量少子电荷，突然反偏时电荷不能瞬间消失 → 需要时间反向恢复 → 限制了二极管的开关速度（高频应用要选恢复时间短的）

**一句话记忆：** 反偏靠"势垒"（越偏越薄电容越小），正偏靠"扩散"（电流越大电容越大）。

## 二极管的微变等效和稳压二极管
### 二极管的微变等效
![[msedge_VRdp9H3ZgM.png|500]]
**二极管的微变等效**（交流小信号模型）：在静态工作点附近，把二极管等效成一个**动态电阻**，用于分析小信号交流电路。
**1. 核心概念：动态电阻 r_d**
$$r_d = \frac{dU}{dI} = \frac{n U_T}{I_D}$$
由电流方程 求导得出：$$
I = I_S\left(e^{\frac{U}{U_T}} - 1\right)
$$
- `U_T ≈ 26 mV`（室温），n 为理想因子（常取 1）
- `I_D`：静态工作点电流（直流偏置电流）
> 常温下工程简化：`r_d ≈ 26 mV / I_D`（n=1 时）

**2. 物理含义**
- 是工作点处曲线的**斜率倒数**（切线斜率），不是直流电阻 `R = U_D/I_D`
- 是**非线性参数**：随 `I_D` 变化——`I_D` 越大，`r_d` 越小
- 只对**小信号**成立（信号幅度远小于 26mV 时近似线性）
**3. 微变等效电路**
```
交流通路：二极管 ──→  等效为电阻 r_d
直流分析：先求静态工作点 I_D（用直流等效：0.7V 恒压降）
```
解题两步骤：
1. **直流分析**：用恒压降模型求 `I_D`（静态工作点）
2. **交流分析**：用 `r_d = U_T/I_D` 替换二极管，算交流量
**4. 与直流等效的区别（易混淆点）**

| | 直流等效 | 微变等效 |
|---|---|---|
| 分析对象 | 大信号/直流工作点 | 小信号交流 |
| 等效元件 | 0.7V 恒压源/开路 | 动态电阻 r_d |
| 前提 | 任意信号 | 静态点附近小信号 |

**6. 注意**：稳压管也有微变等效——`r_Z = ΔU/ΔI`（动态电阻），稳压管工作时要选 `r_Z` 小的（曲线陡），稳压效果好。这与二极管 `r_d` 同源：都是工作点切线斜率。

**一句话总结：** 微变等效 = 先直流求 `I_D`，再代入 `r_d = 26mV/I_D` 换成电阻，只用于静态点附近的小信号分析——"静态点决定斜率，斜率决定交流电阻"。
### 稳压二极管

### 电流放大作用
三极管的电流放大作用：用很小的基极电流 I_B 控制很大的集电极电流 I_C——本质是"电流控制电流源"。$$I_C = \beta I_B \qquad I_E = I_C + I_B = (1+\beta)I_B$$

### 晶体管内部载流子运动与外部电流
![[msedge_mr55AW7QRZ.png|500]]
1. 发射结正偏
	- 发射区的自由电子向基区扩展,基区的空穴同时也向发射区扩散
	- 产生了两个电流,I_EN和I_EP
	- I_EN是自由电子向基区扩散,I_EP是空穴向发射区扩散
	- 因为两边浓度差距太大,两个电流和一,都是I_EN
2. 基区
	- 自由电子在基区继续扩散,会穿过基区到达集电区
	- 自由点在在基区会和空穴复合,复合的电子流出,基区又产生了空穴
	- 会成比例,近似固定的比例,扩散的速度是不变的
	- I_B和I_CN成比例
3. 集电区反偏
	- 集电区收集电子
	- 集电区反偏向基区产生一个电场,自由电子被电场收集
	- 保证浓度梯度不变,自由电子扩散速度保持不变
4. 放大系数
**放大系数**——描述放大器放大能力的参数，分三类：电流放大、电压放大、功率放大。
**1. 电流放大系数**
**① 三极管的 β（直流）与 β（交流）**
$$\beta = \frac{I_C}{I_B} \qquad \beta_{交流} = \frac{\Delta I_C}{\Delta I_B}$$
- 含义：集电极电流是基极电流的多少倍（20~200，典型 100）
- 直流 β 与交流 β 数值接近，工程常不区分
- 决定因素：基区厚度、掺杂浓度等工艺参数（基区薄、轻掺杂 → 复合少 → β 大）

**② 电流增益 A_i（放大器整体）**$$A_i = \frac{I_o}{I_i}$$
**2. 电压放大系数（增益）**$$A_u = \frac{U_o}{U_i}$$
- 共射放大电路：`A_u = -β·R_C/r_be`（负号表示反相）
- 数值：几十 ~ 几百倍
- 工程上常用**分贝（dB）** 表示：`A_u(dB) = 20·lg|A_u|`（如 A_u = 100 → 40dB）
**3. 功率放大系数** $$A_p = \frac{P_o}{P_i} = A_u × A_i$$
- 单位用 dB：`A_p(dB) = 10·lg A_p`
- 三极管放大的是功率吗？——是"功率增益"，但**能量来自电源 V_CC**，三极管只起控制作用（呼应前面笔记）
**4. 易混点（必区分）**

| | β（三极管参数） | A_u（电路参数） |
|---|---|---|
| 属于 | 器件本身的电流放大能力 | 整个放大电路的电压增益 |
| 决定因素 | 工艺结构 | 电路元件（β、R_C、r_be） |
| 是否唯一 | 每个管子固定值 | 随电路配置而变 |

**5. 增益的 dB 速记**

| 倍数 | dB |
|---|---|
| 2 倍 | 6 dB |
| 10 倍 | 20 dB |
| 100 倍 | 40 dB |
| 1000 倍 | 60 dB |

（电压/电流用 20lg，功率用 10lg）
**一句话总结：** 
放大系数分电流（β = I_C/I_B）、电压（A_u = -βR_C/r_be）、功率（A_p = A_u·A_i）三档；
β 是管子固有属性，A_u 是电路属性，工程上用 dB 表示。

![[msedge_Y707bBgh0z.png]]
三个具体变化
 1. 曲线族整体上移（最核心的变化）

对电路的实际后果
温度↑（环境温度升高） → I_CBO↑（集电结反向饱和电流增大，漏电流变大） → 且 β↑（电流放大倍数增大，放大能力增强） → I_C↑（集电极电流增大，流过集电极的电流变大了） → Q 点上移（静态工作点沿负载线向上移动，靠近饱和区） → 逼近饱和区（工作点进入输出电压压缩区） → U_CE 动态范围被压缩（集电极与发射极之间的电压摆动空间变小） → 输出波形下半部被削平（输出电压负半周被饱和区"切掉"），产生饱和失真（波形底部平坦的畸变）

 温度升高使集电结反向饱和电流 I_CBO 增大、电流放大倍数 β 增大，导致集电极电流 I_C 增大，静态工作点 Q 沿负载线上移而逼近饱和区。这压缩了 U_CE 的动态范围，使输出波形负半周被饱和区削平，产生饱和失真。
## MOS管的工作原理
一、与三极管相比，在输出回路输出相同的电流，需要的输入电流的代价更小，同时因为少子不参与导电，场效应管受温度影响小，温度稳定性高。
二、两种场效应管的介绍：
1.结型场效应管：
（1）结构：
![](https://i1.hdslb.com/bfs/note/d975ef954f4ed4cf59f991033a0fcae123b5d876.jpg@672w_!web-note.webp)
两个N区都是高掺杂，中间的非耗尽层称为导电通道；

（2）工作原理：首先明确，对于N沟道结型场效应管，u_GS是不能＞0的，因为u_GS>0时，PN结导通，u_GS不能实现对沟道电流的控制，所以下面的u_GS增大全部指的是大小增大，不是数学意义上的增大；

①u_DS=0，u_GS增大时，耗尽层加宽，沟道变窄，沟道电阻增大，当增大到某一数值时，耗尽层完全闭合，沟道电阻变为无穷大（就是PN结加反向电压），临界条件记为u_GS(off)；

②当u_GS(off)<u_GS<0时，u_DS不算太大时，由于u_GD逐渐减小，靠近漏极的导电沟道逐渐变窄，但不影响沟道电阻，随后出现一个预夹断点，此时若u_DS继续增大，则耗尽层闭合部分沿着沟道延伸，此时u_DS的增大几乎全部用于克服夹断区延伸产生的更大的阻力，从外部看，i_D恒流；

③当u_DS继续增大时，由于管内充满耗尽区，所以可能会发生耗尽区击穿（二极管的反向击穿），此时i_D再一次增大

2.绝缘栅型场效应管（应用更广）（MOS管）：
（1）N沟道增强型MOS管：
①结构：
![](https://i1.hdslb.com/bfs/note/87b60152e7ce1077b7ecffdbc40413a95db446dd.jpg@672w_!web-note.webp)
（上面的阴影部分是二氧化硅，下面的阴影部分是PN结）
（符号中的箭头依然指向PN结导通的方向，比如N沟道中gs为N区B为P区）
g：栅极（和其它两级都绝缘）（类比基极）
s：源极（载流子发源地）（类比发射极）
d：漏极（载流子漏出处）（类比集电极）
d与s之间没有很大的区别，如果B和s没有连在一起，ds可互换
![[msedge_YLfkpdggQs.png]]
②工作原理：
I.u_DS=0且u_GS=0时，整个电路可以等效为两个PN结反向背靠背连接在电源两侧，显然是不可能导通的，此时没有漏极电流；

II.当u_DS=0且u_GS>0时，刚开始的过程可以理解如下：u_GS>0，由于二氧化硅的存在，g-B之间是一个断路，那么g点电位比B高（形成电场），由于P区的载流子是空穴，那么在电场作用下空穴向B移动。<font color="#ff0000">那么最靠近g的地方几乎没有空穴，形成了一个“耗尽层”</font>，（注意前面PN结的耗尽层是因为自由电子与空穴的复合导致某一区域没有载流子，而这里是因为电场让载流子做定向移动到B处导致靠近g处的地方没有载流子）（空穴到B之后最多到栅极处，因为二氧化硅的作用下它们回不到衬底里面了）；此时u_GS若继续上升，不光可以排斥g极附近的空穴，还可以吸引“大量”的自由电子（是少子，因为电场增强到一定值才吸上来很多）<font color="#ff0000">在g极附近聚集形成反型层，此时由于两个N+区域也是自由电子为多子，所以两个N+和反型层整体连通了，形成N沟道</font>；N沟道可以类比电阻，u_GS越大，沟道越宽，ds之间的电阻越小，至此，我们得到了一个<font color="#ff0000">可以用电压控制的可变电阻器</font>，使得沟道出现的临界电压定义为开启电压U_GS(th)。
![[msedge_yuRCX3Umm1.png]]
III.在II的基础上，保持u_GS不变，u_DS>0时,沟道右侧的电势可以近似理解为g点电势减去d点电势u_GD=u_GS-u_DS；起初当u_DS很小的时候（u_DS<u_GS-u_GS(th),可由），u_DS对沟道右侧电势影响很小，亦即沟道保持开放和畅通，<font color="#ff0000">此时我们可以将沟道等效为一个线性电阻，且u_GS越大，线性电阻阻值越小，图像斜率越高；</font>
![[msedge_zRIrWrHKif.png]]
当u_DS继续增大时（u_DS=u_GS-u_GS(th)），此时沟道的漏极一侧出现夹断点，称为预夹断，但是夹断点<font color="#ff0000">不是完全闭合的</font>，会露一小条缝给电子通过(可以假设，如果真的夹断没电流，那么u_DS=0，那么右侧沟道压降就是u_GS，沟道应该处于开启状态），随着u_DS继续增大，夹断区延长，u_DS增加的部分都去对抗增加的电阻了，此时每一个u_GS有一个确定的i_D

写出来应该恰好是一个二次方程$$\boldsymbol{i_D=\frac12\mu_n C_{ox}\frac{W}{L}(u_{GS}-U_{GS(th)})^2}$$

|uGS​−UGS(th)​|**过驱动电压（有效电压）**，记为 Uov​|

（2）N沟道耗尽型MOS管：

与增强型不同的是，耗尽型MOS管中在绝缘SiO2绝缘层中加入了大量的正离子（相当于人为先制造一个电场），那么即使u_GS=0，也会形成反型层沟道，当且仅当u_GS为负且达到某一值时，反型层会消失，没有了导电沟道，这个临界值称为夹断电压u_GS(off)，其余的规律和增强型相同。

三、场效应管的主要参数：

1.饱和漏极电流I_DSS:对于结型场效应管，在u_GS=0V情况下产生预夹断的漏极电流，是转移特性二次项的系数；

2.直流输入电阻R_GS（DC）:栅—源电压与栅极电流之比；

3.低频跨导g_m：转移特性曲线上某一点的斜率，表示i_D的变化量与引起它变化的u_GS之比，类比晶体管的β，由此可构建放大电路；
