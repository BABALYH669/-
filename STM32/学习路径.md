## 🎯 最终版学习路线：8周计划

### 📌 第0周预热：复习定时器（1天）

**为什么在这里？**
定时器是ADC触发、PWM、DMA请求、RTC补偿、FreeRTOS系统嘀嗒的基础。必须彻底过关。

- **前置知识**：无（已学过）
- **核心概念**：时基（PSC + ARR）、更新事件、输出比较、PWM频率/占空比计算、捕获/编码器模式。
- **寄存器**：
    - `TIM_PSC`（预分频器）、`TIM_ARR`（自动重装载）
    - `TIM_CR1`的`CEN`（计数使能）、`UDIS`（更新禁止）
    - `TIM_DIER`的`UIE`（更新中断使能）、`UDE`（更新DMA触发）
    - `TIM_CCMRx`设置PWM模式，`TIM_CCER`使能通道，`TIM_CCRx`设占空比
- **HAL**：`HAL_TIM_Base_Start_IT()`、`HAL_TIM_PWM_Start()`
- **练习**：
    1. 1秒中断翻转LED（验证时基）
    2. 输出50Hz舵机PWM，调节占空比使其在0°~180°转动
    3. 用逻辑分析仪观察更新事件和PWM波形

### 📌 第1周：串口 + DMA（2天）

**核心**：将UART从“中断每字节”升级为“DMA整包传输”，解放CPU；同时获得高效的调试手段。

- **前置知识**：UART基本收发、定时器、中断
- **核心概念**：DMA传输方向、循环/普通模式、外设地址固定、内存地址递增、传输完成中断
- **寄存器**：
    - `DMA_CCRx`：方向（`DIR`）、内存增量（`MINC`）、外设增量（`PINC`）、循环（`CIRC`）、传输完成中断（`TCIE`）
    - `DMA_CNDTR`：传输数量（自动递减）
    - `DMA_CPARx`：外设地址（如`&USART1->DR`）
    - `DMA_CMARx`：内存地址
    - `USART_CR3`：`DMAT`（发送DMA使能）、`DMAR`（接收DMA使能）
- **HAL**：`HAL_UART_Transmit_DMA()`、`HAL_UART_Receive_DMA()`、空闲中断回调（手动添加）
- **练习**：
    1. 发送：用DMA发送一串数据（如"Hello\0"），主循环不阻塞
    2. 接收：结合IDLE中断 + DMA，实现不定长接收，解析命令（`on`/`off`控制LED）
    3. 效率对比：用逻辑分析仪观察当发送大量数据时，中断法和DMA法的CPU占用区别

---

### 📌 第2天：外部中断（1天）

**核心**：掌握GPIO中断配置和去抖技巧，为后续传感器（MPU6050运动检测）等实时响应做准备。

- **前置知识**：NVIC、中断优先级分组
- **核心概念**：EXTI线号与引脚对应（PA0→EXTI0）、上升/下降沿、软件去抖
- **寄存器**：
    - `EXTI_IMR`：中断屏蔽寄存器（对应线）
    - `EXTI_RTSR` / `EXTI_FTSR`：边沿触发选择
    - `EXTI_PR`：挂起标志，写1清除
    - `AFIO_EXTICRx`：将GPIO引脚映射到EXTI线（需使能AFIO时钟）
- **HAL**：`HAL_GPIO_EXTI_IRQHandler()` → `HAL_GPIO_EXTI_Callback()`
- **练习**：
    1. 按键（外部中断）控制LED翻转
    2. 实现“长按2秒进入待机模式”（结合低功耗部分，先用串口模拟）

---

### 📌 第3天~第4天：ADC + DMA（2~3天）

**核心**：进入模拟世界，实现多通道连续采样；DMA自动搬运，CPU几乎零负担。

- **前置知识**：定时器、DMA、中断
- **核心概念**：规则通道/注入通道、扫描模式、采样时间、参考电压、DMA搬移
- **寄存器**：
    - `ADC_CR2`：`EXTSEL[3:0]`（触发源）、`CONT`（连续）、`ADON`（开启）
    - `ADC_SMPR1/2`：采样时间（1.5~239.5周期）
    - `ADC_SQR1~3`：通道序列（`SQ1`、`SQ2`...）
    - `ADC_DR`：转换结果（DMA自动读取）
- **HAL**：`HAL_ADC_Start_DMA(&hadc, buffer, length)`、`HAL_ADC_ConvCpltCallback()`
- **练习**：
    1. 单通道测量电位器，串口打印电压值（公式：`V = ADC*3.3/4096`）
    2. 双通道（光敏+电位器），定时器1ms触发，DMA自动采集，PWM根据光照调节LED亮度
    3. 用逻辑分析仪看ADC转换时间与DMA时序

---

### 📌 第5天~第6天：DAC + DMA（可选，2天）

**核心**：输出模拟波形，与ADC形成完整模拟通路；配合定时器+DMA生成任意波形，是面试亮点。

- **前置知识**：定时器、DMA、ADC
- **核心概念**：波形表（Look-Up Table）、DMA循环模式、输出缓冲、波形类型（正弦/三角/锯齿）
- **寄存器**：
    - `DAC_CR`：`EN1`（使能通道）、`TSEL1[2:0]`（触发源，定时器TRGO）
    - `DAC_DHR12R1`：12位右对齐数据存放
    - 波形生成：DMA将预存的`sin_table[256]`循环加载到`DHR`
- **HAL**：`HAL_DAC_Start_DMA()`
- **练习**：
    1. 输出固定电压（如1.65V），用万用表测量
    2. 输出1kHz正弦波（256点），用ADC回采并打印到串口（或显示在OLED上）

---

### 📌 第6天~第7天：SPI + OLED（2天）

**核心**：第一个可视化里程碑，学会高速同步总线；也能为后续驱动SD卡、闪存打基础。

- **前置知识**：GPIO、时钟、DMA
- **核心概念**：CPOL/CPHA四模式、片选模拟、全双工、数据帧格式
- **寄存器**：
    - `SPI_CR1`：`MSTR`（主）、`BR[2:0]`（分频）、`CPOL`/`CPHA`、`SPE`（使能）
    - `SPI_DR`：数据寄存器（写入即发送，读取即接收）
    - `SPI_SR`：`TXE`（发送空）、`RXNE`（接收非空）
    - `SPI_CR2`：`TXDMAEN`/`RXDMAEN`（DMA请求使能）
- **HAL**：`HAL_SPI_Transmit()`、`HAL_SPI_TransmitReceive()`，也可用DMA
- **实践**：
    1. 驱动SSD1306 OLED显示固定字符
    2. 将ADC采集到的电压值实时显示在OLED上（数字 + 柱状条）
    3. 拓展：驱动W25Q32 SPI Flash，实现“存储-读取-显示”

---

### 📌 第7天~第8天：I2C + MPU6050（2天）

**核心**：掌握另一种双线总线，首次接入MEMS传感器，实现姿态检测。

- **前置知识**：外部中断、定时器、SPI（总线概念类比）
- **核心概念**：7位地址、ACK/NACK、起始/停止条件、寄存器读取、数据融合
- **寄存器（I2C外设）**：
    - `I2C_CR1`：`PE`使能、`START`、`STOP`、`ACK`
    - `I2C_SR1`：`SB`（起始完成）、`ADDR`（地址匹配）、`TXE`、`RXNE`、`BTF`
    - `I2C_DR`：数据寄存器
    - 使用HAL可以避开底层状态机，但建议通过手册理解
- **MPU6050要点**：
    - 地址：AD0=0→0x68
    - 关键寄存器：`PWR_MGMT_1`（唤醒）、`ACCEL_CONFIG`（量程）、`ACCEL_XOUT_H`等
    - 读取6轴原始值（16位有符号）+ 温度
- **HAL**：`HAL_I2C_Master_Transmit()`/`Receive()` / `HAL_I2C_Mem_Read()`
- **练习**：
    1. 读取WHO_AM_I（0x75），验证通信
    2. 定时10ms读取六轴数据，用串口打印
    3. 结合OLED画一个“水平气泡”或简单的姿态指示

---

### 📌 第9天~第10天：RTC + 低功耗（2天）

**核心**：让时间成为系统的参数，实现定时唤醒、日历功能；低功耗是产品化关键。

- **前置知识**：外部中断、定时器
- **核心概念**：后备供电、32.768kHz晶振、分频系数、闹钟、停机/待机模式
- **RTC寄存器**（注意操作前需写保护）：
    - `RTC_CRH`：中断使能（秒/闹钟/溢出）
    - `RTC_CNT`：32位计数器
    - `RTC_PRLL`/`RTC_PRLH`：分频系数，配合32kHz得到1Hz
- **低功耗模式**：
    - 睡眠：CPU停，外设继续（`HAL_PWR_EnterSLEEPMode()`）
    - 停机：内压降停，所有时钟停，可由外部中断或RTC唤醒（`HAL_PWR_EnterSTOPMode()`）
    - 待机：最深，RTC和WKUP能唤醒（`HAL_PWR_EnterSTANDBYMode()`）
- **HAL**：`HAL_RTC_SetTime()`/`GetTime()`、`HAL_RTC_SetAlarm_IT()`
- **练习**：
    1. 通过串口设置时间和闹钟，闹钟触发时点亮LED
    2. 进入停机模式，RTC每10秒唤醒，采集ADC值，再睡眠，测量功耗（万用表测电流）
    3. 记录每周温度（用RTC时间戳保存到Flash）

---

### 📌 第11天~第13天：FSMC + TFT LCD（3天）

**核心**：大结局！用并行总线驱动彩屏，实现图形界面，综合之前所有外设。

- **前置知识**：定时器、ADC、SPI/I2C、存储器映射
- **核心概念**：FSMC映射、8080时序、地址线做RS区分命令/数据、LCD初始化和刷屏
- **寄存器**：
    - `FSMC_BCRx`：`MTYP`（存储器类型）、`MBKEN`（使能）
    - `FSMC_BTRx`：`ADDSET`（地址建立）、`DATAST`（数据保持）
    - 映射地址：例如 `0x6C000000`（NE2片选），向此地址写16位数据即为数据，向 `0x6C000001`（A0=1）写即为命令。
- **HAL**：通常用指针直接操作：`(uint16_t*) (0x6C000000) = data;`
- **实践**：
    1. 驱动ILI9341LCD，画色块、画圆、显示字符
    2. 显示ADC实时波形（滚动显示）
    3. 显示MPU6050姿态（用图形化指针和坐标轴）
    4. 添加FreeRTOS后，可以将显示作为一个独立任务（后续第10步）

---

### 📌 第14天~第15天：FreeRTOS（2天，可选但强烈推荐）

**核心**：从裸机到操作系统，提升代码结构、实时性、可维护性，是实习高频考点。

- **前置知识**：中断、定时器、队列、信号量概念
- **核心概念**：任务创建与优先级、临界区、信号量、消息队列、软件定时器、守护任务
- **移植**：CubeMX一键生成FreeRTOS配置，或手动移植（推荐CMSIS RTOS v1/v2）
- **关键接口**：
    - `xTaskCreate()` / `xTaskCreateStatic()`
    - `xQueueSend()` / `xQueueReceive()`
    - `xSemaphoreTake()` / `xSemaphoreGive()`
    - `vTaskDelayUntil()`（周期性任务）
- **与已有外设结合**：
    - 任务1：ADC采集（优先级高，1ms周期）
    - 任务2：数据处理（滤波、计算）
    - 任务3：LCD刷新（优先级低，尽量少占用CPU）
    - 任务4：串口命令解析（等待消息队列）
- **练习**：
    1. 创建两个任务：一个1秒翻转LED，一个2秒打印“Hello”
    2. 用队列传递ADC数据，在另一个任务中显示到OLED
    3. 使用互斥量保护SPI访问（因为OLED和Flash可能共享SPI）

---

### 📌 第16天~第17天：CAN（选学，2天）

**核心**：工业通信必备，理解报文ID、仲裁、错误处理。

- **前置知识**：定时器、中断、UART
- **核心概念**：标准帧（11位ID）与扩展帧（29位ID）、数据帧/远程帧、过滤器
- **寄存器**：
    - `CAN_MCR`：`INRQ`（初始化请求）、`SLEEP`
    - `CAN_BTR`：位时序（BS1/BS2/SJW）
    - `CAN_TIxR`：标识符、帧类型、发送邮箱
    - `CAN_TDTxR`：数据长度
    - `CAN_TDLxR` / `CAN_TDHxR`：数据字节
    - 接收：`CAN_RFIxR`、`CAN_RDTxR`、`CAN_RDLxR`、...、`CAN_FFA1R`等
- **HAL**：`HAL_CAN_Start()`、`HAL_CAN_AddTxMessage()`、`HAL_CAN_GetRxMessage()`
- **练习**：
    1. 使用环回模式（不回发检查，内部回环）实现自收发
    2. 两块板通过CAN收发数据（或USB转CAN模块与PC通信）
    3. 设计简单协议：ID=0x01发送“温度”，ID=0x02回复“温度值”

---

### 📌 第18天~第19天：USB（选学，2天）

**核心**：人机交互高频需求，虚拟串口（CDC）和HID是最常用。

- **前置知识**：中断、DMA、描述符概念
- **核心概念**：设备描述符、配置描述符、接口描述符、端点描述符、报告描述符
- **关键**：使用STM32CubeMX自动生成USB设备工程（选CDC或HID）
- **HAL**：`CDC_Transmit_FS()`、`CDC_Receive_FS()`（在回调中接收）
- **练习**：
    1. 实现虚拟串口，电脑端显示为COM口，双向通信
    2. 实现HID键盘，板子按键触发PC输出“a”
    3. 实现HID自定义设备，用作数据采集器

## 📚 每个模块的“黄金学习四步法”

1. **读手册**：找对应外设的寄存器描述（STM32F103参考手册），只看与当前实验相关的章节。
2. **画框图**：理解外设内部结构（如ADC的模拟多路选择器、DMA通道仲裁）。
3. **动手实验**：先用CubeMX生成初始化代码，再手动修改寄存器（可混合HAL + 寄存器操作）。
4. **问自己**：如果面试官让我用寄存器配一个XXX功能，我能立刻说出哪几个寄存器、哪个位吗？

## 🧪 综合项目建议（第6~7周）

**项目名称**：智能环境数据记录仪

**功能描述**：

- 采集：ADC（光照）、I2C（温度、湿度，如SHT30）、MPU6050（振动）
- 处理：FreeRTOS任务A采集 → 队列 → 任务B处理（滑动平均、异常检测）
- 显示：TFT LCD实时显示数据波形和数字
- 存储：SPI Flash记录每10分钟的数据（带RTC时间戳）
- 通信：USB虚拟串口连接PC，可读取历史数据或更新采样间隔
- 低功耗：无操作5分钟进入待机，RTC每10分钟唤醒采集一次，完成后继续睡眠

**技术亮点**（面试可以吹）：

- 所有外设均使用DMA传输，CPU负载极低
- 使用FreeRTOS消息队列解耦采集与处理
- 实现低功耗模式，待机电流<10μA
- 代码模块化，每个外设有独立驱动文件
