## 一、I²C 通信与 OLED 驱动核心笔记

### 1. I²C 通信基本步骤（像给助理写信）

| 步骤 | 名称 | 含义 |
| --- | --- | --- |
| 1 | 起始信号 | 主机宣布开始通信 |
| 2 | 从机地址 | 指名道姓（如 0x78） |
| 3 | 应答 ACK | 从机回答“在！” |
| 4 | 控制字节 | 告知下面数据的性质：0x00=命令，0x40=显示数据 |
| 5 | 数据字节 | 发送真正的命令或像素点阵 |
| 6 | 应答/停止 | 确认接收，然后停止通信 |

### 2. “写命令”与“写数据”的本质区别

- `**OLED_WriteCmd(0xAE)**`：
先发控制字节 `0x00`，再发数据 `0xAE`。SSD1306 将 `0xAE` 送入命令解码器，查表后执行“关显示”操作。
- `**OLED_WriteData(0xFF)**`：
先发控制字节 `0x40`，再发数据 `0xFF`。芯片直接把 `0xFF` 当成一列8个像素的点亮状态写入 GDDRAM。
- **核心**：相同的字节数值，因为前置的控制字节不同，被芯片分配到了不同的功能通道。

## 二、SSD1306 内部结构与工作原理

### 1. 芯片角色

- SSD1306 是 OLED 屏的驱动控制器，自带 1K 字节 GDDRAM。
- 它负责与 MCU 通信、解析命令、产生扫描时序、升压驱动 OLED 面板。

### 2. 关键内部模块

| 模块 | 作用 |
| --- | --- |
| MCU 接口 | 接收 I²C 命令和数据 |
| 命令解码器 | 执行命令（开关显示、设对比度等） |
| GDDRAM（1K×8） | 128×64 bit 映射，1=亮点，0=灭 |
| 电荷泵 | 3.3V → 7~9V 升压，屏幕不亮常见原因！ |
| COM/SEG 驱动器 | 硬件自动扫描行与列 |

### 3. GDDRAM 与坐标系统

- 屏幕分为 8 页（Page0~Page7），每页 8 行，共 64 行。
- 每列 1 字节，字节的 bit0 对应该列第 0 行，bit7 对应该列第 7 行。
- 写数据前先通过命令设定页地址 `0xB0+page` 和列地址（高4位+低4位），然后发 `0x40` 即可连续写入像素。

## 三、OLED 初始化命令逐条功能速查

| 命令序列 | 功能 |
| --- | --- |
| `0xAE` / `0xAF` | 关 / 开显示 |
| `0x20, 0x00` | 水平寻址模式 |
| `0xB0` | 设置起始页 |
| `0xC8` | COM 扫描方向从下到上 |
| `0x00, 0x10` | 设置显示起始列为 0 |
| `0x40` | 显示起始行（0） |
| `0x81, 0xFF` | 对比度最大 |
| `0xA1` | 列左右镜像 |
| `0xA6` | 正常显示（非反白） |
| `0xA8, 0x3F` | 多路复用比 64 |
| `0xD3, 0x00` | 垂直偏移为 0 |
| `0xD5, 0xF0` | 时钟分频 / 频率 |
| `0xD9, 0x22` | 预充电周期 |
| `0xDA, 0x12` | COM 引脚硬件配置 |
| `0xDB, 0x20` | VCOMH 电压 |
| `**0x8D, 0x14**` | **电荷泵使能（极易遗漏，遗漏→黑屏）** |

## 四、常见黑屏问题与排查

1. **GPIO 未初始化**：必须调用 `iic_init()` 才能让 SCL/SDA 工作。
2. **SDA 无上拉**：开漏输出必须使能内部上拉 (`GPIO_PULLUP`) 或接外部 4.7kΩ 电阻。
3. **电荷泵未使能**：缺少 `0x8D, 0x14` 命令，屏幕完全无显示。
4. **扫描方向错误**：`0xC8` 和 `0xA1` 若与实际模组不匹配，图像会上、下或左、右颠倒，调整这两个命令即可。

## 五、理解本质的思维模型

- I²C 通信 = **地址** + **控制字节（命令/数据）** + **有效载荷**。
- 控制字节就是“通道选择器”，决定了数据流向命令寄存器还是 GDDRAM。
- OLED 初始化就是一次性把所有“电视机菜单”（显示模式、扫描方向、对比度、电荷泵等）配置好，之后只往 GDDRAM 写像素图形即可。
