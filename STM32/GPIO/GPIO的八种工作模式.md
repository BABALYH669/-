# 先总分类

4 种 **输入模式**（只看不发）
4 种 **输出模式**（只发不看 / 外设发）

| 序号 | 工作模式 | HAL库宏定义（Mode） | 配合 Pull |
| --- | --- | --- | --- |
| 1 | **浮空输入** | `GPIO_MODE_INPUT` | `GPIO_NOPULL` |
| 2 | **上拉输入** | `GPIO_MODE_INPUT` | `GPIO_PULLUP` |
| 3 | **下拉输入** | `GPIO_MODE_INPUT` | `GPIO_PULLDOWN` |
| 4 | **模拟输入** | `GPIO_MODE_ANALOG` | `GPIO_NOPULL` |
| 5 | **开漏输出** | `GPIO_MODE_OUTPUT_OD` | `GPIO_NOPULL` / 上拉 |
| 6 | **推挽输出** | `GPIO_MODE_OUTPUT_PP` | `GPIO_NOPULL` / 上拉/下拉 |
| 7 | **推挽复用输出** | `GPIO_MODE_AF_PP` | `GPIO_NOPULL` / 上拉/下拉 |
| 8 | **开漏复用输出** | `GPIO_MODE_AF_OD` | `GPIO_NOPULL` / 上拉 |

# 一、输入模式（4 种）

共同特点：

- 输出的 MOS 管全部关闭，引脚**只用来读电平**
- 除了「模拟输入」，其他都经过**施密特触发器**整形、抗干扰

## 1. 浮空输入（IN_FLOATING）

- 内部：**上拉、下拉电阻全都关闭**
- 电平状态：完全由**外部电路**决定
- 没有外部信号时：电平**飘忽不定**（高、低、乱跳都可能）
- HAL库函数:GPIO_MODE_INPUT
- 适用场景：
    - 外部已经有明确电平的信号（比如串口 RX、传感器数字输出）
    - 按键外部自己加上拉/下拉电阻

## 2. 上拉输入（IPU）

- 内部：打开**弱上拉电阻**（30~50KΩ）
- 电平状态：
    - 没外部信号 → 默认**高电平**
    - 外部接 GND → 被拉成低电平
- HAL库函数:GPIO_MODE_INPUT 配合  GPIO_PULLUP 是实现上拉输入
- 适用场景：
    - **按键检测最常用**
按键一端接引脚，一端接 GND，松开是高，按下是低，不用外接电阻

## 3. 下拉输入（IPD）

- 内部：打开**弱下拉电阻**
- 电平状态：
    - 没外部信号 → 默认**低电平**
    - 外部接 VCC → 被拉成高电平
- HAL库函数:GPIO_MODE_INPUT 配合 GPIO_PULLDOWN 是实现下拉输入
- 适用场景：
    - 按键接 3.3V 的情况
    - 实际用得很少

## 4. 模拟输入（AIN）

- 内部：
    - 关闭施密特触发器
    - 关闭上下拉电阻
    - 直接连到片上 **ADC**
- 特点：不走数字电路，只传**模拟电压**（0~3.3V）
- HAL库函数:GPIO_MODE_ANALOG 
- 适用场景：
    - 读电压、温度、光敏等**模拟量**
    - 凡是要用 ADC 的引脚，必须设成模拟输入

# 二、输出模式（4 种）

共同特点：

- 用来**输出高低电平**
- 分两类：
    - 通用输出：CPU 直接控制
    - 复用输出：由串口、SPI、定时器等**外设**控制

## 5. 通用推挽输出（Out_PP）

- 结构：**PMOS + NMOS 轮流导通**
    - 输出高 → PMOS 导通 → 接 3.3V
    - 输出低 → NMOS 导通 → 接 GND
- 特点：
    - 芯片**主动输出高低电平**
    - 驱动能力强、速度快
- HAL库函数:GPIO_MODE_OUTPUT_PP
- 适用场景：
    - 控制 LED、蜂鸣器、继电器
    - 普通 IO 口随便输出高低

## 6. 通用开漏输出（Out_OD）

- 结构：**只用 NMOS，PMOS 永远断开**
    - 输出低 → NMOS 导通 → 拉到 GND
    - 输出高 → NMOS 断开 → **引脚悬空（高阻）**
- 特点：
    - **自己出不了高电平**，必须外接上拉电阻
    - 多个开漏输出可以接在一起，实现「线与」
- HAL库函数:GPIO_MODE_OUTPUT_OD
- 适用场景：
    - I2C 通信总线
    - 需要**电平转换**（外部上拉 5V，实现 3.3V→5V 输出）

## 7. 复用推挽输出（AF_PP）

- 结构：还是推挽（PMOS+NMOS）
- 区别：
    - 不是 CPU 控制，而是**片内外设直接控制**
- HAL库函数:GPIO_MODE_AF_PP
- 适用场景：
    - 串口 TX、SPI、PWM 输出
    - 定时器通道、DAC 输出等

## 8. 复用开漏输出（AF_OD）

- 结构：还是开漏（只 NMOS）
- 区别：由**外设**控制，不是 GPIO 寄存器
- HAL库函数:GPIO_MODE_AF_OD
- 适用场景：
    - I2C、CAN 等通信总线
    - 外设需要开漏结构的场合

# 最简记忆口诀

- 想**读按键** → 上拉输入
- 想**读模拟量** → 模拟输入
- 想**点灯、发信号** → 通用推挽
- 想**接 I2C** → 复用开漏
- 想**用 PWM、串口** → 复用推挽
- 啥都不用、悬空读信号 → 浮空输入
