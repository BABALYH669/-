## 📘 STM32F103 定时器系列实验笔记

## (基本定时器 · 通用定时器 · 高级定时器)

---

## 第一部分：基本定时器实验 (TIM6)

### 一、实验内容

- 使用 **TIM6** 实现精确的 **定时中断**，控制 LED 周期性闪烁。

### 二、实验步骤与核心配置

1. **时钟源**：TIM6 挂接在 **APB1** 总线上（36MHz 经倍频后为 72MHz）。
2. **参数设置**：
```c
btim_timx_base_init(7200-1, 5000-1);
```
    - 预分频器 (PSC) = 7199，自动重装载值 (ARR) = 4999。
    - 定时器时钟 = 72MHz / 7200 = **10kHz**。
    - 溢出频率 = 10kHz / 5000 = **2Hz**，即每 **500ms** 产生一次更新中断。
3. **启动定时器中断**：
```c
HAL_TIM_Base_Start_IT(&g_timx_handle);
```
4. **中断服务与回调**：
    - `TIM6_IRQHandler` → `HAL_TIM_IRQHandler` → `HAL_TIM_PeriodElapsedCallback`。
    - 在回调中翻转 LED0：`LED0_TOGGLE()`。
5. **主循环**：只做延时，所有控制交给定时器中断。

### 三、实验结论

- 基本定时器只能做 **定时功能**，没有输入/输出通道。
- 通过调整 PSC 和 ARR 可随意改变定时周期，精度取决于时钟源（内部 72MHz 非常精确）。
- 非常适合做简单的周期性任务调度或时基。

## 第二部分：通用定时器实验 (TIM2/3/5)

### 一、实验一：外部计数模式 (TIM2)

### 实验内容

- TIM2 配置为 **外部时钟模式1**，通过 **PA0** 输入的脉冲进行计数。

### 关键配置

```c
TIM2 配置为从模式，触发源 TI1FP1（即 PA0 引脚输入）。
CounterMode = UP，Period = 65535。
启动输入捕获通道1：HAL_TIM_IC_Start(&handle, TIM_CHANNEL_1);
```

### 实验现象

- 按下 KEY0 清零计数器。
- 串口实时打印当前计数值。
- PA0 每来一个外部脉冲（由信号源提供或另一定时器产生），计数器加 1。

### 结论

- 通用定时器支持 **外部脉冲计数**，常用于编码器、流量计等场景。

---

### 二、实验二：输入捕获测脉宽 (TIM5)

### 实验内容

- TIM5 通道1 (PA0) 配置为 **输入捕获**，测量输入高电平持续时间。

### 核心逻辑

6. **第一次上升沿**：记录计数值设为 0，并切换为下降沿捕获。
7. **随后的下降沿**：读取当前计数值 → 得到高电平脉宽。
8. **更新中断**用于处理超时（计数器溢出次数），最终结果还要加上溢出次数 × 65536。
9. 主函数按以下公式计算实际时间：
```c
temp = (溢出次数 * 65536) + 捕获值;  // 单位：定时器计数周期
// 定时器时钟 = 72MHz / (71+1) = 1MHz → 1us
// 所以最终脉宽单位为微秒(us)
```

### 结论

- 输入捕获是测量信号频率/占空比的基础方法，需配合溢出计数换算长时间。
- 手动切换边沿极性是实现连续测量的常见方式。

---

### 三、实验三：PWM 输出 (TIM3)

### 实验内容

- TIM3 通道2 (PB5) 输出 **PWM**，通过动态调整占空比实现 LED **呼吸灯**效果。

### 关键配置

```c
Period = 500-1，Prescaler = 72-1 → PWM 频率 = 72MHz / 72 / 500 = 2kHz。
OCMode = PWM1，CCR2 初始值 = 250 (50% 占空比)。
```

### 主循环

```c
ledrpwmval 在 0~300 间递增/递减，更新 CCR2：
__HAL_TIM_SET_COMPARE(&handle, TIM_CHANNEL_2, ledrpwmval);
```

### 结论

- 只需改变 CCRx 寄存器的值即可灵活控制占空比，在 LED 调光、电机调速中广泛应用。

## 第三部分：高级定时器实验 (TIM1/8)

### 一、互补 PWM 带死区 (TIM1)

### 实验内容

- TIM1 CH1 (PE9) 及其互补通道 CH1N (PE8) 输出带 **死区时间** 的互补 PWM。

### 关键配置

```c
atim_timx_cplm_pwm_init(1000-1, 72-1);  // PWM 频率 = 72MHz / 72 / 1000 = 1kHz。
OCMode = PWM1, OCPolarity = HIGH, OCNPolarity = HIGH。
BreakState = TIM_BREAK_ENABLE，AutomaticOutput = ENABLE。
DeadTime 通过 TIM_BreakDeadTimeConfigTypeDef 结构体配置。
```

### 功能调用

```c
atim_timx_cplm_pwm_set(700-1, 250);   // 占空比 70%，死区 250（约 2.77us，取决于 Tdts）。
```

### 结论

- 高级定时器独有的 **互补输出 + 死区插入** 是电机驱动、逆变器等场景的关键功能，防止上下桥臂直通。

---

### 二、比较输出模式 (TIM8)

### 实验内容

- TIM8 四个通道 (PC6~9) 配置为 **比较输出切换模式 (Toggle)**，分别在 CCR 匹配时翻转输出。

### 配置要点

```c
OCMode = TIM_OCMODE_TOGGLE;
CCR1 = 250, CCR2 = 500, CCR3 = 750, CCR4 = 1000。
Period = 1000，计数值 0→1000 递增。
结果：各通道在 25%、50%、75%、100% 周期处翻转，形成多路时序控制信号。
```

### 结论

- 比较输出切换可用于生成多路精确时序脉冲，配合 DMA 可实现波形发生器。

---

### 三、PWM 输入测量 (TIM8)

### 实验内容

- TIM8 CH1 (PC6) 配置为 **PWM 输入**，用一个通道同时捕获输入信号的 **周期** 和 **高电平脉宽**。

### 原理

- CH1 捕获上升沿，CH2 捕获下降沿（映射到同一输入端 TI1），从模式配置为 Reset，每次上升沿自动复位计数器。
- 因此 CH2 值 = 高电平脉宽，CH1 值 = 周期。
- 串口输出计算后的频率、高电平时间、周期。

### 结论

- PWM 输入模式极大简化了脉宽 + 周期测量，只需一个引脚。

---

### 四、指定脉冲数输出 (TIM8)

### 实验内容

- TIM8 输出 **指定个数** 的 PWM 脉冲后自动关闭。

### 实现原理

10. 利用 **重复计数器 (RCR)** 控制更新事件发生的次数（即 PWM 周期数）。
11. 初始化时调用 `atim_timx_npwm_chy_set(N)`，在更新中断里：
    - 当剩余脉冲数 `g_npwm_remain` 非零时，设置 `RCR = remain - 1`，继续产生更新事件。
    - 当 `remain == 0` 时，关闭定时器，脉冲停止。

### 结论

- 高级定时器的重复计数器配合中断可精确控制输出脉冲个数，常用于步进电机、伺服控制。

## 第四部分：三种定时器横向对比总结

### 🔴 相同点

12. **基本结构相同**：都包含预分频器 (PSC)、自动重装载寄存器 (ARR)、计数器 (CNT)，都是向上/向下计数。
13. **定时功能**：三种均可实现精确定时和中断。
14. **时钟源**：均来自内部时钟 (CK_INT)，由 RCC 提供。
15. **HAL 库驱动方式**：均通过 `TIM_HandleTypeDef` 初始化，并有对应的 `HAL_TIM_xxx_Init` / `Start` 函数。
16. **更新事件 (UEV)** 均能产生中断或 DMA 请求。

---

### 🟡 不同点（要点！）

| **特性** | **基本定时器 (TIM6/7)** | **通用定时器 (TIM2~5)** | **高级定时器 (TIM1/8)** |
| --- | --- | --- | --- |
| **主要功能** | 仅定时 | 定时、输入捕获、输出比较、PWM | 定时、捕获、PWM、**互补输出**、**死区**、**刹车** |
| **通道数** | 无 | 4 个独立通道 | 4 通道 + 3 互补通道 |
| **计数器位数** | 16 位自动重装载 | 16 位 | 16 位 |
| **编码器模式** | 不支持 | 支持 (TI1/TI2 编码器) | 支持 |
| **互补输出** | 不支持 | 不支持 | 支持 (CHxN) |
| **死区插入** | 不支持 | 不支持 | 支持，可编程死区时间 |
| **刹车功能** | 不支持 | 不支持 | 支持 (Bkin 引脚紧急关断输出) |
| **重复计数器** | 不支持 | 不支持 | 支持 (RCR，控制更新事件在N次溢出后触发) |
| **DMA 请求** | 仅更新事件 | 捕获/比较/更新均可触发 DMA | 捕获/比较/更新均可触发 DMA |
| **特殊应用** | 简单时基，操作系统心跳 | 电机测速（编码器）、PWM 调速、输入捕获测频 | 电机控制（六步 PWM）、逆变器、数字电源 |
| **时钟总线** | APB1 | TIM2~5 在 APB1（72MHz） | TIM1/8 在 APB2（72MHz） |
| **输出引脚重映射灵活性** | 无 | 部分支持 | 支持，且有 BKIN 复用 |

---

### 🔴 难点与重点提炼

### 基本定时器 (BTIM)

- **重点**：时钟树中 APB1 倍频的细节（36MHz→72MHz），及公式 `Tout = (PSC+1)(ARR+1)/Tclk`。
- **难点**：无，最简单。
- **要点**：只用于定时，省资源，无 GPIO 占用。

### 通用定时器 (GTIM)

- **重点**：输入捕获与输出比较的灵活配置，PWM 模式 1/2 的区别。
- **难点**：
    - **输入捕获计算脉宽**：需处理溢出计数器，正确组合 16 位捕获值和溢出次数，防止竞争。
    - **从模式配置**：外部计数、复位模式等常被忽略，但非常实用。
- **要点**：通用的 4 通道设计几乎能满足所有非电机驱动场景需求。

### 高级定时器 (ATIM)

- **重点**：
    - **互补输出 + 死区**：必须正确配置 `TIM_BreakDeadTimeConfigTypeDef`。
    - **重复计数器 RCR**：理解它只用于高级定时器，且影响更新事件的中断频率。
- **难点**：
    - **PWM 输入模式**：映射关系复杂 (IC1→TI1, IC2→TI1 间接)，需要同时配置从模式复位。
    - **死区时间计算**：需查阅手册中 DTG 位与时钟分频 (Tdts) 的对应关系。
    - **刹车功能**：硬件响应，需正确配置极性，且软件可配合产生中断。
- **要点**：是电机和电源控制的核心，务必掌握其三种高级特性（互补、死区、刹车）。

---

### 六、总结

本次系列实验完整覆盖了 STM32F103 三种定时器的核心应用。

- **基本定时器** 让你理解时基产生原理。
- **通用定时器** 扩展到信号捕获与生成。
- **高级定时器** 专为复杂控制优化。

在实际项目中，根据任务复杂度选择对应类型：简单记时用 BTIM，常规控制用 GTIM，电机/逆变器必用 ATIM。
