## 数据通信的基础概念

1. 串行/并行通信
    1. 串行通信:数据逐位按顺序一次传输,  线路简单、抗干扰强、适合**远距离传输**
    2. 并行通信:数据各位通过多条线同时传输   速度快，但**抗干扰差、成本高、距离短**
2. 单工/半双工/全双工通信
    3. 单工:数据只能沿一个方向传输
    4. 半双工:数据可以沿两个方向传输,但需要分时进行
    5. 全双工:数据可以同时进行双向传输
3. 同步/异步通信
    6. 同步:共用同一时钟信号
    7. 异步:没有时钟信号,在数据信号中加入起始位和停止位
4. 波特率
    8. 比特率:每秒种传送的比特数,bit/s
    9. 波特率:每秒传送的码元数,Baud
    10. 比特率 = 波特率*log2 M ,M表示每个码元承载的信息量
    11. 二进制系统中,波特率数值上等于比特率
5. 常见的串行通信接口
    12. UART / USART
        1. 全双工、异步、点对点
        2. 2 根线：TX（发）、RX（收）
        3. 用于：调试串口、蓝牙模块、GPS、WiFi 模块
    13. SPI
        4. 同步、全双工、高速
        5. 4 根线：SCLK、MOSI、MISO、CS
        6. 用于：Flash、屏幕、传感器
    14. I2C
        7. 同步、半双工、多主机
        8. 2 根线：SDA、SCL
        9. 用于：EEPROM、温湿度传感器、RTC
    15. CAN
        10. 工业级、抗干扰强、多设备
        11. 用于：汽车电子、工业控制
    16. USB
        12. 高速串行、主从结构
        13. 日常最常见外设接口
    17. RS485
        14. 差分信号、远距离、多机
        15. 工业串口常用

## 波特率=时钟频率/采样倍数*波特率因子

## 波特率因子=时钟频率/采样倍数*波特率

时钟频率:看系统时钟STM32F103是72MHz和36MHz

采样倍率:一般是16

波特率因子(USARTDIV):USARTDIV=DIV_Mantissa+(DIV_Ftaction/16)

                                                                 左移四个位  ⬇    

写入波特率寄存器: USART1→BRR = USARTDIV * 16  +  0.5

                                                                                四舍五入   ⬆

```c
unti16_t matissa;
unti16_t fraction;
波特率因子=时钟频率/波特率*采样倍数 采样倍数是16是STM32内部用16倍过采样
USARTDIV = 72000000/115200*16 = 39.0625
整数部分
mantissa = 39;
小数部分 乘16是逆运算(也是左移四个位的意思) +0.5是四舍五入取整
fraction = 0.0625*16+0.5 = 0x01; 
左移四个位,因为mantissa寄存器是[15:4] fraction寄存器是[3:0]
USART1->BRR = (mantissa<<4) +fraction;
```

4.串口MSP回调函数
void HAL_UART_MspInit(UART_handleTypeDef *huart)
{
	GPIO_InitTypeDef gpio_init_struct;
	if(huart->Instance ==USART1  如果是串口1,进行串口1 MSP初始化
	{
		4.1使能USART1和对应的IO时钟
		__HAL_RCC_USART1_CLK_ENABLE();
		__HAL_RCC_GPIOA_CLK_ENABLE(); GPIOx是根据串口x决定的
		3.2初始化IO  
		PA9 TX引脚 TX是发送端 要设置推挽输出+高速模式 不用设置上下拉电阻
		gpio_init_struct.Pin = GPIO_PIN_x;//初始化引脚编号
    gpio_init_struct.Mode = GPIO_MODE_AF_PP;//复用推挽输出
    gpio_init_struct.Speed = GPIO_SPEED_FREQ_HIGH; //GPIO发送速度为高速
    gpio_init_struct.Pull = GPIO_PULLUP;//开启上拉电阻,提供高电平F1系列不存在上下拉可以不管
    
    GPIOx是根据串口x决定的
    HAL_GPIO_Init(GPIOA,&gpio_init_struct);//调用HAL库函数HAL_GPIO_Init
    
		PA10 RX引脚 RX是接收端,要设置输入模式
		gpio_init_struct.Pin = GPIO_PIN_x;//初始化引脚编号
    gpio_init_struct.Mode = GPIO_MODE_INPUT;//输入
    gpio_init_struct.Pull = GPIO_PULLUP;//接收不需要设置值上下拉电阻
    gpio_init_struct.Speed = GPIO_SPEED_FREQ_HIGH; //GPIO发送速度为高速接收不需要高速
    GPIOx是根据串口x决定的
    HAL_GPIO_Init(GPIOA,&gpio_init_struct);//调用HAL库函数HAL_GPIO_Init
		
		4.3使能USART1中断,设置优先级
		HAL_NVIC_SetPriority(中断号,抢占优先级,相应优先级)
		4.4使能中断
		HAL_NVIC_EnableIRQ(中断号);
	}
}
5.串口1中断服务函数
void USART1_IRQHandler(void)
{
	异步通信:HAL_UART_IRQHandler(串口句柄);
	同步通信:HAL_USART_IRQHandler(串口句柄);
	这个函数会清除中断标志并调用Callback函数
	HAL_UART_IRQHandler(&g_uart1_handle);
	
}
6.串口数据接收完成回调函数
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
	if(huart->Instance == USART1)
	{
			接收到数据赋值为1
			g_usart1_rx_flag = 1;	
			因为HAL_UART_IRQHandler这个函数会清除中断 所以要再次调用中断
			重启接收
			HAL_UART_Receive_IT(句柄,缓冲区,字节数)
			HAL_UART_Receive_IT(&g_uart1_handle,(uint8_t*)g_rx_buffer,1);
	}
}
HAL_UART_IRQHandler这函数会清除中断标志
HAL_UART_Receive_IT这个函数会赋予中断标志
USART1_IRQHandler->HAL_UART_IRQHandler->HAL_UART_RxCpltCallback这个函数会执行中断
